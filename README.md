# Note Widget（笔记小部件）

把一条 Obsidian 笔记固定显示在**独立于主窗口的无边框桌面窗口**里：像便签一样常驻桌面，随时看一眼今日待办或速记。

> 仅支持 Windows 上的桌面版 Obsidian（Electron）。移动端不支持。

## 功能

- **独立桌面窗口**：无边框、可拖动（拖动标题栏）、可拖拽边缘缩放。
- **显示指定笔记的渲染内容**：Markdown 会被正常渲染（标题、列表、表格、图片、内部链接等），并跟随当前 Obsidian 主题的配色与字体。
- **指定目标笔记**：在设置里填笔记路径，或点「选择」从库中挑一条；重启后保留。
- **自动更新**：笔记内容被修改保存后，小部件自动刷新。
- **始终置顶**：可在设置里开启/关闭，也可点窗口右上角的图钉按钮随时切换。
- **贴边自动隐藏**：把窗口拖到屏幕任意一条边，它会自动收起，只在边缘留下一条很窄的触发条；鼠标移入时滑出，移出后自动收回。
- **位置与尺寸记忆**：窗口位置、大小、透明度、缩放都会保存。

## 安装

### 方式一：手动构建后放入插件目录

```powershell
cd obsidian-note-widget
npm install
npm run build
```

构建产物是仓库根目录下的 `main.js`（以及已有的 `manifest.json`、`styles.css`）。

然后在你的库（Vault）里创建插件目录：

```
<你的库>\.obsidian\plugins\obsidian-note-widget\
```

把 `main.js`、`manifest.json`、`styles.css` 三个文件复制进去（**目录名必须是 `obsidian-note-widget`**，与 manifest 里的 `id` 一致）。

### 方式二：开发时软链接

```powershell
# 在仓库目录执行，把整个项目链接到插件目录（改完 npm run build 后在 Obsidian 里重新加载插件即可）
New-Item -ItemType Junction -Path "<你的库>\.obsidian\plugins\obsidian-note-widget" -Target "C:\path\to\obsidian-note-widget"
```

开发时用 `npm run dev` 进入 watch 模式，自动重建 `main.js`。

## 启用

1. 打开 Obsidian → 设置 → 第三方插件（社区插件）。
2. 如果处于「安全模式 / 受限模式」，先关闭它。
3. 点「刷新」后找到 **Note Widget**，启用。

## 日常使用

- 打开/关闭小部件：
  - 左侧边栏的 **面板图标**；
  - 命令面板（`Ctrl+P`）里的「打开/关闭笔记小部件」；
  - 设置 → 笔记小部件 → 「打开 / 关闭」按钮。
- 指定笔记：设置 → 笔记小部件 → 「目标笔记」，输入库内相对路径（如 `Notes/今日待办.md`），或点「选择」搜索笔记。下方会提示是否已在库中找到该文件。
- 移动窗口：按住顶部标题栏拖动。拖动窗口四边可缩放。
- 置顶：点标题栏右侧的图钉按钮，或在设置里切换「始终置顶」。
- 贴边隐藏：把窗口拖到屏幕的左/右/上/下边缘松手，窗口会贴边收起为一条细条。
  - 鼠标移到细条上 → 滑出；
  - 鼠标离开窗口 → 自动收回；
  - 不想要这个行为时，在设置里关闭「贴边自动隐藏」。
- 刷新：点标题栏的刷新按钮（命令面板里也有「刷新笔记小部件」）。一般不需要手动刷新。
- 关闭：点标题栏的关闭按钮，或再次执行「打开/关闭笔记小部件」。

窗口最后的显示状态会被记住：如果关闭 Obsidian 时小部件是打开的，下次启动会自动恢复（包括目标笔记与置顶设置）。

## 设置项

| 设置 | 说明 |
| --- | --- |
| 目标笔记 | 库内相对路径，或从库中选择 |
| 始终置顶 | 小部件是否位于其他窗口之上 |
| 贴边自动隐藏 | 拖到屏幕边缘后是否收起为触发条 |
| 窗口不透明度 | 0.4 – 1，便于透出后面的内容 |
| 内容缩放 | 0.7 – 1.6，调整小部件里的字号与排版比例 |
| 窗口宽度 / 高度 | 也可直接拖拽窗口边缘调整，会自动记忆 |

## 已知限制

- 小部件里显示的是渲染结果的**快照**：由 Dataview 等插件动态生成的内容、Mermaid 等异步渲染块，可能需要点一下刷新按钮才会更新。
- 小部件里的复选框、可编辑嵌入块是只读的，不能直接在窗口里勾选或输入。
- 内部链接会在 Obsidian 主窗口中打开对应笔记；外部链接交给系统默认浏览器。
- 小部件窗口是通过 Electron 的 `remote` 能力创建的，仅桌面端可用；如果拿不到该能力时会直接报错而不影响主程序。

## 目录结构

```
obsidian-note-widget/
├── manifest.json       # 插件清单
├── main.js             # 构建产物（npm run build 生成）
├── styles.css          # 插件在主窗口里的样式
├── esbuild.config.mjs  # 构建脚本
├── tsconfig.json
└── src/
    ├── main.ts         # 插件入口：命令、事件、设置持久化
    ├── settings.ts     # 设置项与小部件界面（含笔记选择器）
    ├── widget.ts       # 小部件窗口：创建、渲染、置顶、贴边隐藏
    └── widget-ui.ts    # 小部件窗口的 HTML 外壳、样式与交互脚本
```
