# Note Widget（笔记小部件）

把一条 Obsidian 笔记固定显示在**独立于主窗口的无边框桌面窗口**里：像便签一样常驻桌面，随时看一眼今日待办或速记。

> 仅支持桌面版 Obsidian（通过 Electron 的 `remote` 创建独立窗口）。移动端不支持。

## 功能

- **独立桌面窗口**：无边框、透明背景；拖动顶部标题栏移动，拖动窗口边缘缩放。
- **显示指定笔记的渲染内容**：Markdown 正常渲染（标题、列表、表格、图片、内部链接等），并跟随当前 Obsidian 主题的配色、字体与 CSS 片段。
- **只读实时预览**：小部件里只展示渲染结果，不提供 Markdown 源码编辑。目标笔记在主窗口里输入（尚未保存）时也会同步刷新；保存后同样自动更新，一般不需要手动刷新。
- **待办可点击勾选**：渲染模式下直接点任务前的复选框，即可勾选/取消并写回原笔记。
  - 兼容 `- [ ]` / `- [x]` / `[X]` 以及 `*`、`+`、有序列表和引用前缀的写法，只改勾选字符，不动其他内容；围栏代码块内的内容不会被当成任务行。
  - 若点击前笔记已被别处修改，小部件会提示并刷新，不会静默覆盖。
- **小部件内选择笔记**：点标题栏的放大镜按钮，在小部件里搜索并切换库中任意 Markdown 笔记；输入关键字按文件名或路径过滤（支持中文），当前笔记带「当前」标记；键盘 `↑` / `↓` 移动、`Enter` 确认、`Esc` 或点击面板外部关闭。选择会保存，重启后仍然生效。
- **打开到主窗口编辑**：点标题栏的铅笔按钮，把当前笔记在 Obsidian 主窗口打开（已打开则复用标签），并切换到源码（编辑）模式、把主窗口带到前台；小部件本身始终是只读预览。
- **始终置顶**：可在设置里开启/关闭，也可点标题栏的图钉按钮随时切换。
- **贴边自动隐藏**：把窗口拖到屏幕任意一条边并松手，窗口会滑入并收起为一根贴边把手；鼠标移到把手上滑出完整面板，鼠标离开后自动收回。
  - 把手固定长度 96 DIP（沿屏幕边缘方向），文案固定为「Obsidian小部件」。
  - 可见薄条只有 20 DIP 厚；窗口本身受 Windows 最小窗口尺寸限制保留 38 DIP，与薄条之间的部分是真透明区域，鼠标可直接穿透到桌面。
  - 贴左/右时文字整体旋转 90° 沿边缘排布；贴上/下时文字横排。
  - 文案颜色跟随主题：浅色主题纯黑 `#000000`，深色主题纯白 `#ffffff`，均为不透明色。
  - 不需要这个行为时，在设置里关闭「贴边自动隐藏」，已收起的窗口会立即恢复成完整面板。
- **窗口内选择笔记**：见上方放大镜按钮；输入关键字按文件名或路径过滤（支持中文），当前笔记带「当前」标记。
  - 键盘操作：`↑` / `↓` 移动选择，`Enter` 确认，`Esc` 或点击面板外部关闭。
- **状态记忆**：窗口位置、宽高、不透明度、缩放都会保存；关闭 Obsidian 时小部件是打开的，下次启动会自动恢复（目标笔记与置顶设置一并恢复）。
- **未选择笔记时的空状态**：小部件里直接提示去设置里填路径或点「选择」。

## 安装

### 方式一：构建后手动放入插件目录

```powershell
cd obsidian-note-widget
npm install
npm run build
```

构建产物是插件目录下的 `main.js`（与仓库里已有的 `manifest.json`、`styles.css` 一起使用）。

然后在你的库（Vault）里创建插件目录：

```
<你的库>\.obsidian\plugins\obsidian-note-widget\
```

把 `main.js`、`manifest.json`、`styles.css` 三个文件复制进去（**目录名必须是 `obsidian-note-widget`**，与 manifest 里的 `id` 一致）。

### 方式二：开发时软链接

```powershell
# 在仓库目录执行，把整个项目链接到插件目录（改完 npm run build 后在 Obsidian 里重新加载插件即可）
New-Item -ItemType Junction -Path "<你的库>\.obsidian\plugins\obsidian-note-widget" -Target "C:\path\to\obsidian-note-widget"
```

开发时用 `npm run dev` 进入 watch 模式，自动重建 `main.js`。

## 启用

1. 打开 Obsidian → 设置 → 第三方插件（社区插件）。
2. 如果处于「安全模式 / 受限模式」，先关闭它。
3. 点「刷新」后找到 **Note Widget**，启用。

## 日常使用

- 打开/关闭小部件：
  - 左侧边栏的 **面板图标**；
  - 命令面板（`Ctrl+P`）里的「打开/关闭笔记小部件」；
  - 设置 → 笔记小部件 → 「打开 / 关闭」按钮。
- 指定笔记：设置 → 笔记小部件 → 「目标笔记」，输入库内相对路径（如 `Notes/今日待办.md`），或点「选择」搜索笔记。下方会提示是否已在库中找到该文件。
- 标题栏按钮从左到右：
  - **放大镜**：在小部件内搜索并切换笔记；
  - **铅笔**：在主窗口打开当前笔记并进入源码模式（小部件里不提供编辑）；
  - **图钉**：切换始终置顶；
  - **刷新**：强制重新渲染（命令面板里也有「刷新笔记小部件」）；
  - **关闭**：关闭小部件。
- 移动窗口：按住顶部标题栏拖动；拖动窗口四边可缩放，尺寸会自动记忆。
- 贴边隐藏：把窗口拖到屏幕的左/右/上/下边缘松手，窗口会滑入并收起为贴边把手。
  - 鼠标移到把手上 → 滑出完整面板；
  - 鼠标离开面板 → 自动收回把手；
  - 收起状态下，把手以外的透明区域不会挡住桌面上的点击；
  - 关闭「贴边自动隐藏」后不再收起，已收起的会立即展开。
- 勾选待办：渲染模式下直接点任务前的复选框即可勾选/取消，改动会立即写回原笔记并刷新显示。
- 内部链接会在 Obsidian 主窗口打开对应笔记；外部链接（`http`/`https`/`mailto`）交给系统默认浏览器。

## 设置项

| 设置 | 说明 |
| --- | --- |
| 目标笔记 | 库内相对路径，或从库中选择；支持省略 `.md` 后缀 |
| 始终置顶 | 小部件是否位于其他窗口之上 |
| 贴边自动隐藏 | 拖到屏幕边缘后是否收起为贴边把手 |
| 窗口不透明度 | 0.4 – 1，便于透出后面的内容 |
| 内容缩放 | 0.7 – 1.6，调整小部件里的字号与排版比例 |
| 窗口宽度 | 240 – 800，也可直接拖拽窗口边缘调整，会自动记忆 |
| 窗口高度 | 200 – 900，同上 |

窗口位置、宽高、透明度、缩放与「上次是否打开」都会持久化到插件数据里。

## 已知限制

- 小部件里显示的是渲染结果的**快照**：由 Dataview 等插件动态生成的内容、Mermaid 等异步渲染块，可能需要点一下刷新按钮才会更新。
- 渲染模式下只有待办复选框可写回；其他内容都是只读的，修改笔记请点铅笔按钮到主窗口编辑。
- 贴左/右时把手文字是整体旋转 90°（不是逐字竖排）；真实窗口厚度受 Windows 最小窗口尺寸限制为 38 DIP，可见薄条为 20 DIP，其余是透明区。
- 小部件窗口通过 Electron 的 `remote`（`@electron/remote`）创建，仅桌面端可用；拿不到该能力时会记录错误并放弃打开，不影响主程序。

## 目录结构

```
obsidian-note-widget/
├── manifest.json       # 插件清单
├── main.js             # 构建产物（npm run build 生成）
├── styles.css          # 插件在主窗口里的样式
├── esbuild.config.mjs  # 构建脚本
├── tsconfig.json
└── src/
    ├── main.ts         # 插件入口：命令、事件、设置持久化
    ├── settings.ts     # 设置项与设置面板
    ├── widget.ts       # 小部件窗口：创建、渲染、置顶、贴边收起
    └── widget-ui.ts    # 小部件窗口的 HTML 外壳、样式与交互脚本
```
